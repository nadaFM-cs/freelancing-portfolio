Kinetix — AI-to-CNC Design Pipeline

Role
Flutter Team Leader
Platform
Mobile (Flutter)
Backend
FastAPI

Led the development of Kinetix, a CNC-integrated mobile application that bridges design and fabrication through AI. Users draw freehand, upload an image, or capture one with the camera, and send it to an AI model over HTTP. The AI processes the image and sends it on to a CNC machine, which brings the design to life.

Also built a prompt-based image generation feature: the AI generates an image from text, and the CNC draws it automatically. The backend runs on FastAPI, keeping the full pipeline seamless and efficient.

  1. InputDraw, upload, camera, or a text prompt
  2. HTTPFlutter sends it to the FastAPI backend
  3. AIModel processes or generates the image
  4. CNCMachine draws the final design

Walletly — Offline Expense Manager App

Type
Personal project
Platform
Mobile (Flutter)
Storage
Hive (fully offline)

Walletly is a fully offline personal expense manager built with Flutter. It helps users track daily spending, organize expenses by category, and stay within a monthly budget, all without needing an internet connection.

  • Add, edit and delete expenses with categories such as Food, Transportation, Shopping, and more
  • Monthly budget with a clear view of what is spent and what is left
  • Dashboard with charts that visualize spending by category
  • Local data storage with Hive, so everything works offline and loads instantly
  • Clean Material 3 UI with light and dark mode
  • State management with GetX for a responsive, well-structured codebase

Built with a clean architecture and a polished UI, with a focus on understanding the why behind each design decision.

Notes App — Location-Aware Notes in Flutter

Type
Mobile app
Platform
Mobile (Flutter)
Storage
SQLite via floor

A notes application built with Flutter that lets users add, edit and delete notes, and attach to each note the location where it was written. Data is stored in a local SQLite database through the floor library, with GetX handling state management.

  • Automatic location capture at writing time, resolved to a readable address with reverse geocoding
  • Shake-to-delete: clear all notes with a shake of the device
  • Fully custom UI/UX with smooth page transitions and interactions
  • Performance tuning, including fewer unnecessary database reads
  • Comprehensive error handling for location failures, denied permissions, and unavailable services
